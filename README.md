# ai-pm-path · IT 项目经理转 AI 岗位学习路径

一个纯静态、零依赖的学习导航网站。面向有 IT 项目管理背景、想转到 AI 岗位的人，解决三个问题：**走哪条路、学什么、怎么验收**。

**在线地址**：https://yinzhijuan.github.io/ai-pm-path/

---

## 一、这个网站解决什么问题

转岗学习最常见的失败方式不是不努力，而是：

- 收藏了一堆课，不知道先学哪个、学到什么程度算够
- 学了一堆概念，面试被问"RAG 各环节代价是什么"答不上来
- 没有产出物，简历上没有能拿出手的东西

所以这个网站不提供"课程列表"，而是提供**带验收标准的路径**：

```
选轨道 → 看阶段目标 → 学资源并打卡 → 勾选验收标准 → 攒够就能投简历
```

每条路径都明确写清"学到 S2 结束（约 8–10 周）即可开始投简历"，避免陷入无限准备。

## 二、三条轨道怎么选

| 轨道 | 定位 | 总时长 | 适合谁 |
|---|---|---|---|
| **PM 单轨** | AI 产品经理 | 121 小时 | 想尽快转岗、对写代码兴趣不大、沟通与项目管理是最强项 |
| **Dev 单轨** | AI 应用开发工程师 | 177 小时 | 愿意投入时间写代码、能接受和年轻开发者拼工程速度 |
| **双轨（推荐）** | PM 为主 + 补齐开发 | 179 小时 | 用技术深度给产品判断力兜底，**转化率最高** |

**默认推荐双轨**：你的项目管理经验是纯技术出身的人短期补不上的，反过来用技术能力给产品判断力兜底，能同时投 PM 和应用开发两类岗位。

⚠️ 注意：双轨比单轨多约 40% 时长。如果每周只能投入 5 小时，建议先走 PM 单轨。

### 时间投入换算

选择每周可投入小时数后，网站会实时换算总周数：

- **每周 5 小时**：工作日每天 1 小时 + 周末 1 小时（项目忙、只能挤时间）
- **每周 10 小时**：工作日每天 1.5 小时 + 周末半天（大多数人能长期维持）
- **每周 15 小时**：工作日每天 2 小时 + 周末一整天（已决定全力转岗）

## 三、学习路径（以推荐双轨为例）

| 阶段 | 主题 | 周数 | 小时 |
|---|---|---|---|
| S1 | 认知对齐：AI 到底能干什么 | 2w | 22h |
| S2 | Python 与 LLM 调用 | 3w | 35h |
| S3 | RAG：把知识装进模型 | 4w | 45h |
| S4 | Agent：让模型去做事 | 4w | 45h |
| S5 | 产品化、评测与求职 | 3w | 32h |

**两个关键判断（不是随便排的）**：

1. **S3 的 RAG 必须打穿** — 这是目前 AI 岗位最刚性、最高频的技能，也是 PM 面试被问穿的重灾区。至少要能说清：切分策略怎么选、检索为什么失效、召回差时优先调哪一环。
2. **评测是稀缺能力** — 大多数人只会"跑起来"，不会"证明它更好"。能把评测讲清楚的人，在面试里是少数派。

共 **38 条**，全部经过 curl 批量验真（剔除失效链接、修正错误仓库地址）：

- **按类型**：课程 9 / 文档 9 / 社区 7 / 代码 5 / 工具 5 / 论文 3

## 五、功能

- **轨道 × 时间档** 实时换算，切换即刻看到总周数变化
- **阶段卡片展开**：阶段目标 / PM 的既有优势 / 验收标准 / 配套资源
- **进度追踪**：验收标准逐条勾选、资源逐条打卡
- **资源库筛选**：按类型 / 中文 / 免费 / 关键词搜索
- **我的进度**：完成百分比 + 累计小时
- **数据管理**：导出 JSON 备份 / 清空重来（清空会保留当前轨道设置）

## 六、本地运行

```bash
cd ai-pm-path
python3 -m http.server 8124
# 打开 http://127.0.0.1:8124
```

或者双击工作区根目录下的 `启动学习网站.command`，脚本会启动服务并自动打开浏览器。

**无需 npm install，无需构建**，四个文件就是全部。

## 七、文件结构

```
ai-pm-path/
├── index.html     页面骨架
├── styles.css     样式
├── data.js        全部数据（38 条资源 + 3 轨道 × 5 阶段 + 时间档 + 建议）

```

改内容只需动 `data.js`，`app.js` 不需要改。

---

## 八、数据存储说明

学习进度存在**浏览器 localStorage**，key 为 `ai-pm-path-v1`。

这意味着：

- 换浏览器或换设备 → 看到的是空白进度（不是数据丢了）
- 清理浏览器数据 → 进度会清空，重要节点记得用"导出 JSON"备份
- 本地打开和线上访问各存一份，互不相通
